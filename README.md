# OmniNotice E2E Automation (Regression)

Автоматизированные E2E-тесты для платформы **OmniNotice** (админ-панель). Проект покрывает сквозные сценарии регресса (создание и отправка рассылок, история, валидация, обработка ошибок) и API-контракты.

## 🛠 Стек
*   **Playwright**
*   **TypeScript**
*   **Node.js**

## 📊 Текущее покрытие (UI)
На данный момент **11 UI-тестов** проходят успешно. Покрыты следующие блоки:
*   **Happy Path:** Полный сценарий создания и отправки Push-рассылки.
*   **Валидация:** Лимиты полей (заголовок/текст), невалидные URL.
*   **История:** Отображение статусов, сортировка, фильтры, тултипы ошибок.
*   **Обработка ошибок (Моки):**
    *   Ошибка 500 (Internal Server Error) — зафиксирован баг с ложным тостом об успехе.
    *   Частичный успех (Partial success) — проверка, что фронт не врет про полный успех.
*   **Модальное окно:** Отмена подтверждения (сохранение формы), текст подтверждения.

## 📊 Текущее покрытие (API)
В папке `tests/api` находятся тесты на контракт, авторизацию и лимиты.
*(Примечание: тесты на идемпотентность отправки временно закомментированы, так как тестовый стенд возвращает 403 от Doocot).*

## 🚀 Как запустить локально

### 1. Установка зависимостей
```bash
npm install
npx playwright install chromium
2. Настройка окружения
Скопируйте .env.example в .env.dev и заполните данные:

bash
cp .env.example .env.dev
В .env.dev укажите:

UI_LOGIN и UI_PASSWORD (данные для входа в OmniNotice)

DELEGATED_TOKEN (для API-тестов)

PROJECT_ID (заголовок Project-Id из DevTools)

3. Запуск тестов
bash
# Запустить только UI-тесты (11 сценариев)
npm run test:ui

# Запустить только API-тесты
npx playwright test --project=api

# Запустить всё сразу
npm test
4. Просмотр отчета
После прогона тестов откройте HTML-отчет:

bash
npm run test:report

🐞 Найденные баги (автотестами)
Ложный успех при ошибке 500: При падении бэкенда (500) интерфейс показывает зеленый тост «Рассылка успешно отправлена» (см. error-handling.spec.ts).

Отсутствие предпросмотра: В интерфейсе OmniNotice (версия на момент тестирования) отсутствует блок предпросмотра (Preview), хотя он заявлен в ТЗ (REG-CORE-010).
